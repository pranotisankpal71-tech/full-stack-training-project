# Level 4 Final Submission

This repository contains my final internship project submission.  
It is a full-stack web application built with **Node.js, Express, MongoDB, and EJS**.

## Features
- User registration and login with session authentication
- Dashboard with personalized greeting
- Create, view, and manage blog posts
- Comment system for posts
- Bootstrap styling for responsive UI

## Tech Stack
- Node.js
- Express.js
- MongoDB + Mongoose
- EJS templating
- Bootstrap 5
